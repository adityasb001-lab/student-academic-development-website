# Student Academic and Development Website

A professional and responsive productivity website designed for students to manage academic and daily tasks efficiently. The project is built using HTML, CSS, and JavaScript as part of the Fundamentals of Web Design course project.

---

## 📌 Project Overview

Students often struggle with managing academics, assignments, deadlines, and personal development activities due to excessive distractions and poor task organization.

This website provides a simple and user-friendly platform where students can:

- Add tasks
- Edit tasks
- Delete tasks
- Set deadlines
- Organize academic and daily activities
- Improve productivity and time management
