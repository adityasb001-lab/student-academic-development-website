Project brief

Why this website exists

Abstract

Due to the mindless use of social media and doom-scrolling, students often struggle with tracking and prioritizing their tasks. This website helps students manage academic work and physical exercise in a single, easy-to-use interface.

Introduction

In a competitive academic era, students need digital tools that are simple, accessible, and effective. This project provides a user-friendly productivity website that runs in any modern web browser.

Related works

Tools like Google Keep, Todoist, and Notion are powerful, but they can feel advanced or overwhelming for beginners. This project keeps the interface minimal while still offering the core productivity features students need.
